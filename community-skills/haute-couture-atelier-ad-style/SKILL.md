# Haute Couture Atelier Ad Style — Heritage Embroidery Luxury Film

Use this Skill when the user wants a **top-tier haute-couture and high-atelier commercial**: a large Chinese high-embroidery piece presented in a dark luxury space with the lens language of Western high-fashion and craftsmanship films.

Core principle: **spend the budget on restraint, craft and light — warm-gold key light, ordered stitches and one single work of embroidery held throughout; never cheap, never gaudy, never a tourism film.**

The prompt follows the H3 timecoded structure (core concept → four-segment screen description with positive and negative per beat → hard negative list). T2VA only — pure text, no reference image.

---

## 1. Trigger

Use this Skill when the user's request matches any of:

- A luxury fashion / craft atelier brand film
- An embroidery or heritage-craft hero spot presented like Dior Haute Couture or Chanel Métiers d'Art
- A "haute couture" product showcase that must feel expensive, restrained, elegant and mysterious
- A single work of textile/embroidery art shot in macro craft-film style

Do **not** use this Skill when:

- The user wants a tacky / cheap china-chic, generic guofeng or tourism-promo look
- The user wants fast editing, dense subtitles or a voice-over narrator
- The user wants to showcase many different embroidery patterns — this holds one single piece
- A reference image must drive the look (this is pure T2VA)

## 2. Inputs

- A text description of the scene only: a dark luxury space; a large Chinese high-embroidery piece with ruyi (如意) motifs, twining-lotus (缠枝莲) scrollwork, koi and leaf-scroll patterns embroidered on cinnabar-red / ink-blue / jet-black premium silk; warm-gold key light, soft side-rim light, macro highlights sweeping the surface; dramatic chiaroscuro on dark grounds.
- Duration 15s, aspect 16:9, 24fps, top-tier haute-couture / high-atelier ad look.
- No reference image, no first frame — T2VA.

## 3. Core Concept

15 seconds, 16:9, a top-tier Western haute-couture and high-atelier ad. In a dark luxury space, a large Chinese high-embroidery piece (ruyi motifs, twining-lotus scrollwork, koi and leaf-scroll patterns as the main visuals, stitched on cinnabar-red / ink-blue / jet-black premium silk) is repeatedly shown in close-up, shot in the lens language of Dior Haute Couture, Chanel Métiers d'Art, Valentino Haute Couture and Hermès craft films — five-color thread sheen, the order of fine stitches, gold-couched edging and laid-gold opulence, layered dimensional embroidery. Warm-gold key light with soft side-rim light and macro highlights sweeping the surface; dramatic chiaroscuro against the dark background. Luxurious, restrained, expensive, elegant, mysterious; slow pushes and lateral moves with soft dissolves; no narration.

## 5. Hard Rules

- **One single embroidery work throughout** — never swap or change the pattern; the same piece stays on screen for the whole film.
- **Craft-ad lens language** — five-color thread sheen, ordered fine stitches, gold couching and laid-gold opulence, layered dimensional embroidery; macro detail, warm-gold key light, soft side-rim light, slow pushes and lateral moves, soft dissolves.
- **Restrained title system** — any title appears once only, restrained, large negative space, bilingual (Chinese calligraphy title + modern fine secondary line; English in elegant high-luxury serif), in warm gold / antique bronze gold / ivory white.
- **No voice-over, no fast editing** — calm, slow, quiet.
- **No real brand logos or trademarks** — a generic luxury title system only.

## 6. Negative Rules (Do Not)

Voice-over / narration; tacky generic-guofeng; cheap china-chic; tourism-promo feel; over-royal piling-up; frequently swapping the embroidery pattern; a flat mediocre display; oversaturated dense subtitles; real brand logos or trademarks; fast cutting; a loud gaudy grade.
