# 高定工坊广告风格 — 非遗刺绣高奢工艺片

当用户想要一条**顶级高定与高级工坊广告**时使用：在深色高奢空间里，用西方高定时装与工艺影像的镜头语言呈现一大幅中国高级刺绣作品。

核心原则：**把预算花在克制、工艺与光上——暖金主光、有序针脚、全片只守住同一幅刺绣作品；绝不廉价、绝不俗艳、绝不像旅游宣传片。**

提示词遵循 H3 带时间码结构（核心创意 → 四段式画面过程描述，每拍含正向与反向约束 → 硬性反向清单）。仅 T2VA——纯文字，无参考图。

## 1. 触发场景

- 高奢时装 / 工艺工坊品牌片
- 像 Dior Haute Couture、Chanel Métiers d'Art 那样呈现的刺绣或非遗工艺主角片
- 必须昂贵、克制、优雅、神秘的"高定"产品展示
- 以微距工艺片方式呈现的单件纺织 / 刺绣艺术品

**不要用**这个 Skill 的场景：

- 要俗艳 / 廉价国潮、俗套古风或旅游宣传片感
- 要快速剪辑、密集字幕或旁白解说
- 要展示多种刺绣图样——本 Skill 只守住同一幅作品
- 需要参考图驱动画面（本 Skill 是纯 T2VA）

## 2. 输入

- 仅文字场景描述：深色高奢空间；一大幅中国高级刺绣作品，主视觉为如意纹、缠枝莲纹、锦鲤与卷草纹，绣于朱砂红 / 黛蓝 / 墨黑高级丝绸底料；暖金主光 + 柔和侧逆光 + 微距高光扫面；深色背景中的戏剧性明暗。
- 时长 15s、画幅 16:9、24fps、顶级高定 / 高级工坊广告质感。
- 无参考图、无首帧——T2VA。

## 3. 核心创意

15 秒、16:9、顶级西方高奢时装与高级工坊广告风格短片。深色高奢空间里，一大幅中国高级刺绣精品（以如意纹、缠枝莲纹、锦鲤与卷草纹为主视觉，绣于朱砂红 / 黛蓝 / 墨黑高级丝绸底料）的局部被反复特写，拍法借鉴 Dior Haute Couture、Chanel Métiers d'Art、Valentino Haute Couture、Hermès 工艺影像的高定面料与工坊藏品镜头语言：五彩丝线细腻光泽、细密针脚秩序、金线勾边与盘金贵气、立体绣花层次。暖金主光 + 柔和侧逆光 + 微距高光扫面，深色背景中的戏剧性明暗。华丽、克制、昂贵、优雅、神秘；缓慢推近与横移运镜、柔和叠化切镜，无旁白。

## 4. 画面过程描述

| 时间 | 节拍 | 必须发生的内容 |
|---|---|---|
| 0～4秒 | 微距建立 | 暖金主光从侧面打下，微距扫过丝绸底料上起伏的立体绣花与五彩丝线，丝线随光线闪烁细碎光泽，深色背景衬托出刺绣的贵气。不要俗套古风，不要廉价国潮，不要旅游宣传片感。 |
| 4～8秒 | 金线特写 | 镜头缓慢横移，沿金线勾边与局部盘金 / 金属丝线移动，金线反射细碎金光；针脚的秩序与节奏清晰可见，莲瓣与锦鲤鳞片的丝绸光泽在柔和侧逆光中流转。不要更换刺绣图样，全片保持同一幅作品。 |
| 8～12秒 | 气韵中景 | 镜头缓缓拉远，露出如意纹与缠枝莲交错的大面积绣面，立体绣法在戏剧性明暗中起伏，暖金主光扫过，绣面如"可穿戴珠宝"般华丽。不要过度宫廷堆砌，不要密集字幕。 |
| 12～15秒 | 落版收束 | 镜头推至莲花花心高光最亮处，金光满溢后缓缓虚化收束。如出现字幕，仅一次、排版克制、大留白：中英双语（中文书法标题字 + 现代细字副文案，英文优雅高奢衬线体，暖金色 / 古铜金 / 象牙白），像真正高奢品牌海报与影片的标题系统。不要旁白配音，不要快速剪辑。 |

## 5. 硬性规则

- **全片同一幅刺绣作品**——绝不更换图样，同一幅作品贯穿全片。
- **工艺广告镜头语言**——五彩丝线细腻光泽、细密针脚秩序、金线勾边与盘金贵气、立体绣花层次；微距细节、暖金主光、柔和侧逆光、缓慢推近与横移、柔和叠化切镜。
- **克制的标题系统**——任何字幕仅出现一次、排版克制、大留白、中英双语（中文书法标题 + 现代细字副文案；英文优雅高奢衬线体），暖金色 / 古铜金 / 象牙白。
- **无旁白、无快速剪辑**——从容、缓慢、安静。
- **无真实品牌 Logo 与商标**——只用通用高奢标题系统。

## 6. 不想要（反向约束）

旁白；俗套古风；廉价国潮；旅游宣传片感；过度宫廷堆砌；频繁更换刺绣图样；平庸的平面展示；浓艳过饱和字幕；真实品牌 Logo 与商标；快速剪辑；浮夸嘈杂的调色。

## 7. 生成

- 模式：T2VA（纯文字生成）——无参考图、无首帧。
- 15s、16:9、24fps、H3 原生音频：空灵弦乐 + 轻微钢琴 + 极弱金属泛音 + 柔和低频氛围，优雅、华贵、安静；外加工坊极弱环境底噪、丝线与绣架经轴的细微摩擦声。
