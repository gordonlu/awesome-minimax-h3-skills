# 以巧劲制体重 — 落地式酒馆打斗

当用户想要一段**落地、超写实暗黑奇幻酒馆打斗**时使用：精灵游侠 Morwen 用速度、走位与巧劲，在拥挤海港酒馆里放倒巨型半兽人壮汉 Rogar，从一张**双人参考图**出发。

核心原则：**双角色锁死参考图、每一击物理可信、把模型的预算花在真实体重与动量上——绝不漂浮、绝不动漫夸张、绝不超人。**

提示词遵循 H3 三段式结构（参考锁定 → 核心创意 → 带时间码分镜），带硬性反向约束。

---

## 1. 触发场景

- 有真实体重的写实打斗场景 / 酒馆斗殴
- 大卫对歌利亚的近身格斗（小快对大慢）
- 任何必须落地、真实的电影级徒手打斗序列

**不要用**这个 Skill 的场景：

- 想要漂浮、动漫式或超人的打斗
- 想要非物理、魔法为主的战斗
- 没有双人参考图

## 2. 输入

- 一张**双人参考图**（`@图片1`）——锁定两人的形象与体型：
  - **Morwen**——矫健的女性精灵游侠：银白长发编辫束后、墨绿皮甲、布质缠裹、腰间佩剑。
  - **Rogar**——巨型半兽人壮汉：带疤痕的灰褐色皮肤、兽骨铠甲、重型双锤。
  - 仅作形象参考——不作为首帧，不限定构图与调度。
- 时长 15s、画幅 16:9、超写实手持电影感。

## 3. 六个带时间码节拍（15s）

1. **0–2s** 大远景建立：昏暗拥挤的海港酒馆——满座醉醺醺水手、火盆、烟雾、泼洒的蜂蜜酒、喧闹人群。Morwen 警惕穿过；Rogar 在巨大木桌豪饮。无清晰面部大特写、无字幕无 Logo。
2. **2–4s** 近景对峙：Morwen 与 Rogar 四目相对；Rogar 缓缓站起、高过所有人；长凳刮擦、杯子因体重晃动；人群围成打斗圈起哄。接地气手持。
3. **4–7s** 冲突爆发：Rogar 挥出沉重重拳、动量可信；Morwen 堪堪躲过、真实踉跄撞上木桌开裂迸屑；她快速贴地反击其肋部与腿部；人群吼叫、硬币与杯子抛向空中。无漂浮、无动漫翻滚、无超人物理。
4. **7–10s** 打斗升级穿过酒馆：Rogar 抓住 Morwen 扔过一张桌子、桌在她体重下真实碎裂；她地板滚动、自然恢复平衡；Rogar 沉重冲锋、撞碎家具；酒客真实跳开躲避。只允许物理可信的打斗、无穿模穿物。
5. **10–12s** Morwen 以速度与走位智取：再躲一记重击令 Rogar 撞上支撑梁、灰尘碎屑落下；她短暂攀上吧台、以克制的真实动量跃下、锁其手臂借力把他摔得失衡。无失重漂浮、无慢动作。
6. **12–15s** 电影感高潮：Morwen 将 Rogar 重重按倒在碎裂木废墟、地板因冲击震动；她压住他、剑抵喉边；Rogar 在悬殊体重差与疲惫中真实挣扎；人群疯狂欢呼、砸杯。镜头缓慢推向气喘吁吁的 Morwen，汗水、尘土与炉火在两人身上闪烁。

## 4. 硬性规则

- 真实物理、可信身体动量、接地气手持运镜、实拍质感、逼真的碰撞与环境互动。
- 全片两人形象与参考图一致。无漂浮、无动漫式打斗、无超人物理、无不真实翻滚、无失重动作、无模糊角色、无低细节、无卡通、无迟钝反应、无穿模穿物。
- 音乐 / 音效：厚重电影感海港酒馆战斗配乐——低沉鼓点、响亮人群欢呼、木头断裂、金属碰撞、真实肉体打击、火盆环境、杯子摔碎、沉重脚步、粗糙北境氛围。

## 5. 生成

- 模式：I2VA，`@图片1` 仅作双人形象参考——除非明确要求，不作为首帧。
- 15s、16:9、H3 原生音频。
