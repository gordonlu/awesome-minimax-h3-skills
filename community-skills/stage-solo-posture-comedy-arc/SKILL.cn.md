# 单人表演弧｜坐起前倾再释放 — 健身口播喜剧

当用户想要一段**12 秒单人口播喜剧短片**时使用：一个二十多岁的年轻人独自坐在沙发上、面朝镜头，用随口吐槽的方式聊健身，讲出 2-3 个自嘲式笑点。

核心原则：**"聊健身，但要讲笑话"——保持自然吐槽式的闲聊，而不是表演；三段缓慢而有控制的推近让每个笑点落地更有力。**

提示词遵循 H3 三段式结构（核心创意 → 带时间码的分段 → 严格反向约束）。T2VA：纯文字生成，无参考素材。

---

## 1. 触发场景

- "聊某个话题，但讲笑话"的单人喜剧
- 面无表情、自嘲式口播独白
- 必须像自然闲聊而非表演的低调喜剧段子

**不要用**这个 Skill 的场景：

- 想要多人段子、访谈或带群演的 VLOG
- 想要高制作广告感、综艺音效或字幕
- 想要高能量单口表演或夸张反应

## 2. 输入

- 纯文字——无参考图（T2VA，纯文字生成）。
- 时长 12s、画幅 16:9、稳定机位、家常布光、自然表演。
- 主体：一个二十多岁的年轻人，独自坐在沙发上、面朝镜头。

## 3. 分段（带时间码，16:9）

- **0～4 秒（中景）**：普通客厅内景，年轻人坐在沙发上、面朝镜头，双手比划着开口："健身房的年卡，就像我的肌肉——办卡那天，就是它最辉煌的一天。"说完微微摊手。不要广告式精致布光，不要综艺感音效，不要字幕。
- **4～8 秒（轻微推近）**：镜头缓慢推近，他换了个坐姿、叹口气继续说："我的健身计划表只有两栏：'明天开始'和'下周一定'。"表情一本正经。不要观众笑声音轨，不要第二个人物入镜。
- **8～12 秒（再次推近至近景，收束）**：镜头继续推近到近景，他停顿半拍，凑近镜头压低声音："别问我坚持得怎么样——我的健身生涯连'预告片'都算不上，只有一张年卡海报。"说完自己先绷不住笑了一下；镜头停留在他的脸上结束。不要表演过度夸张，不要多余角色入镜。

## 4. 硬性规则

- 全片画面只出现这一个角色，无第二人。
- 自然、随口、自嘲式吐槽——不是真人秀式夸张反应。
- 家常普通布光、稳定机位、笑点处轻微推近。
- 无字幕、无 Logo、无 BGM、无罐头笑声、无综艺音效。
