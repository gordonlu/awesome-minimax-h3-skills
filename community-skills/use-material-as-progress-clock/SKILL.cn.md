# 材料即时间 — 非遗工艺纪录广告

当用户想要一支**非遗工艺纪录广告**、以材料自身外观作为时间指针时使用：苗族银匠以八道工序锻造一件银饰，"银白"作为影片的时间标记，从无到有、越来越多地占据画面。

核心原则：**最终成物锁死参考图、让材料自身的转化（而非特效）标记时间、拍成顶级手工艺品牌新品诞生纪录——而不是旅游宣传片或遗产宣传片。**

提示词遵循 H3 三段式结构（参考锁定 → 核心创意 → 带时间码的八步分镜），含字幕牌规则、受限配色与仅现场声设计。

---

## 1. 触发场景

- 非遗工艺纪录广告
- 手工产品的缓慢优雅工艺纪录
- "从无到有成物"的品牌片
- 以材料转化驱动叙事的工艺片

**不要用**这个 Skill 的场景：

- 想要华丽国潮特效秀或旅游宣传片
- 想要博物馆式展览片
- 没有最终成物参考图

## 2. 输入

- 一张最终银饰作品参考图（`@图片1`）——锁定造型、主体比例、银面颜色、錾刻纹样走向与整体气质，不加不存在的龙、凤、佛像、文字、装饰。
- 包装与工坊场景纯文字描述（无需参考图）。
- 时长 15s、画幅 9:16、字幕驱动、仅现场原声。

## 3. 八道工序（带时间码，9:16）

1. **0–1.7s** 主镜头：深夜昏暗的苗寨吊脚楼工坊，一盏暖灯只照亮双手；陈年粗银粒、深色坩埚、被反复锤击揉合的银料块；双手反复捶压揉成柔软银坯。尚无银白。字幕：第一道 · 锤银成坯。
2. **1.7–3.3s** 极端微距：银料置铁砧锤下，厚块延展成薄而匀的银片；贴得很近可见轻微氧化、细小锤纹、手指压力。字幕保持：锤银成坯。
3. **3.3–5.0s** 主镜头：錾好的银片胎体首次出现；匠人落下第一道花纹——第一个小卷云纹；画面首次出现极微弱暖色反光。字幕：第二道 · 一錾起纹。
4. **5.0–6.8s** 微距插入：凿、压、推、錾银面；几道不足毫米级的细纹形成高低差的浮凸纹样——卷云、缠枝、如意。字幕保持：一錾起纹。
5. **6.8–8.6s** 主镜头：大部分錾刻完成；极缓慢推近，旋转银饰，光线擦过密集錾纹；仍是哑光灰白，尚无抛光银光。字幕：第三道 · 錾刻成纹。
6. **8.6–10.2s** 全片最重要的声画高潮：极端微距，一小团银屑与焊料悬在火光里轻颤；匠人屏息用焊枪把焊料引向接缝；火焰接触瞬间焊料流动，银白第一次大面积出现。字幕：第四道 · 一火成器。
7. **10.2–11.7s** 微距：柔软细布擦过银面，多余焊渣与氧化层被拭去，锐利细密的银色錾纹从暗哑银灰中显现——第二个视觉高潮，明确"暗哑银灰 → 明亮银白"。字幕：第五道 · 银光醒来。
8. **11.7–13.8s** 主镜头 + 插入：成物置于深色木台，双手缓慢旋转检查；随后放入定制包装盒（深色木盒、暖米色软布内衬、素雅无大 Logo 的盒面），盒盖合上。字幕：第六道 · 最后一眼 / 第七道 · 入盒。
9. **13.8–15s** 最终镜头：切到极简现代民族手工艺精品店；一只手将银饰放到展示台中央后退出画面；成物在晨光中完全静止。字幕：第八道 · 上架。画面中央极小文字：贵州苗族银饰 / 一锤成器。终帧须如高端工艺品牌静态产品摄影。

## 4. 字幕牌规则

全片只有一个字幕牌：画面下方三分之一、水平居中、所有镜头位置完全相同；非常克制的圆角矩形、深藏蓝底、暖米白文字；两行（细字工序号 + 粗体极短动作描述）；不移动、不放大缩小、不淡入淡出、不跳动，只在剪辑点瞬间更换文字，始终清楚正确。

## 5. 配色与光线

限制在：陈年银灰、暗哑银白、火暖橙、木黑褐、暖米白、亮银白。前半段灰褐主导、中段暖橙渐现、后半段银白占据视觉中心。银白必须来自真实金属与真实光线——绝不用发光特效。禁止青蓝科技色、霓虹、紫色、赛博朋克、高饱和国潮配色。

## 6. 声音（仅现场原声，无音乐 / 旁白 / 对白）

0–3.3s 清晨安静工坊（轻微环境底噪、银料落砧闷响、密集锤击脆响、手掌揉压摩擦）；3.3–8.6s 进一步降低（錾刀轻碰银面、小锤敲击、极轻碰击、旋转木架细微摩擦）；8.6–10.2s 全片关键声音时刻——其余压低，只留焊枪轻微喷气、火舌舔银的细小噼啪、工具触料细声，焊点落定接近安静；10.2–12.8s 细布擦银、细碎氧化屑摩擦、银饰木架轻转；12.8–15s 折纸、布料摩擦、盒盖轻合，随后进店：作品底座触展台"嗒"一声，最后接近完全安静。
