# 二维角色｜真人接触三级反应 — 贴纸柴犬 vs. 真实夜市

当用户想要一条**扁平 2D 贴纸角色与真实实拍画面同框并互相反应的喜剧短片**时使用：贴纸柴犬旺财往真实炒锅里偷倒辣椒面，被实拍锅铲轻轻敲头，被喂了一口，最后被辣到喷小火焰、像纸片一样翻下塑料矮凳。

核心原则：**一次只出现一只实拍手、贴纸狗绝对扁平、每个反应都是一记干净的跨媒介整活——贴纸无 3D 体积、无写实感、无穿帮。**

提示词遵循 H3 带时间码结构（核心创意 → 五段式画面过程描述，每拍含正向与反向约束 → 硬性反向清单）。仅 T2VA——纯文字，无参考图。

## 1. 触发场景

- 扁平 2D 贴纸 / 纸片角色与真实实拍素材互动
- "贴纸偷倒辣椒 / 被敲头 / 被辣喷火"的反应整活梗
- 跨媒介混搭喜剧短片
- 夜市摊主第一人称颠锅 POV，带一个捣蛋的 2D 小跟班

**不要用**这个 Skill 的场景：

- 要一个完全 3D 或 CGI 角色融入实拍——本 Skill 的贴纸必须肉眼可见地保持扁平
- 要多机位稳定拍摄——本 Skill 是单一固定宽幅 POV，仅轻微手持漂移
- 要对白或旁白——全片无对白
- 需要参考图驱动画面（本 Skill 是纯 T2VA）

## 2. 输入

- 仅文字场景描述：真实夜市炒粉摊、黑色炒粉大铁锅、锅内油亮米粉与绿色配菜滋滋作响冒蒸汽、右侧一张塑料矮凳、坐在凳上的扁平 2D 贴纸柴犬旺财。摊主眼位略向下俯视的第一人称颠锅视角、固定宽幅构图、仅轻微自然手持漂移。
- 时长 10s、画幅 16:9、24fps、一镜到底——无切镜、无转场、无变焦、无大幅重新构图。
- 无参考图、无首帧——T2VA。

## 3. 核心创意

10 秒、16:9、喜剧短片。写实夜市炒粉摊实拍与一个完全扁平的 2D 贴纸角色（贴纸柴犬旺财）同框互动。全片是摊主眼位略向下俯视的第一人称颠锅视角：固定宽幅构图、仅轻微自然手持漂移、无切镜、无转场、无变焦、无大幅重新构图——一镜到底。实拍右手负责炒粉、左手负责端走辣椒罐；旺财偷倒辣椒面被锅铲轻轻敲头，最后被辣到喷小火焰、像纸片一样翻下塑料矮凳。

## 4. 画面过程描述（单一连续镜头）

| 时间 | 节拍 | 必须发生的内容 |
|---|---|---|
| 0～3秒 | 偷倒辣椒 | 固定俯视 POV：黑色炒粉大铁锅略偏画面左中，锅内油亮米粉与绿色配菜滋滋作响、冒自然蒸汽，右侧一张塑料矮凳。实拍右手掌背朝向镜头、拇指朝画面左侧内扣，从右下边缘持唯一一把木柄金属锅铲入画并持续翻炒。贴纸柴犬旺财坐在矮凳上露出坏笑，用自己两只清晰的扁平贴纸爪抱起一个比它脑袋还大的搪瓷辣椒罐，抬起来朝锅里倾倒，干燥红辣椒面成股落下、在粉上堆成显眼的红色小山。全程锅铲不碰罐子，罐子附近不出现实拍手指。伴随食物持续滋滋声与干燥纸片般的倒落声。任一画面不得同时出现两只实拍手；不得出现第二把锅铲；不得出现镜像手、漂浮手、多余手掌。 |
| 3～3.8秒 | 换手交接 | 辣椒面流完全停止、红色小山保持可见。右手把同一把锅铲平放进锅内、完全退出右下边缘，画面短暂无实拍手、锅铲静止躺在锅中。随后空的实拍左手从左上边缘入画（掌背朝镜头、拇指朝画面右侧内扣），直接从旺财两只贴纸爪里接过搪瓷罐、整个退出左上边缘带走——左手全程不碰锅铲。左右手不得同框；不得出现两只左手、重复手臂；左手不得触碰任何餐具。 |
| 3.8～5秒 | 敲头 | 左手完全消失后，同一只右手从右下返回（朝向不变），从锅里拿起同一把锅铲，沿一条连续轨迹抬向旺财：用锅铲平面在它头顶轻轻一碰——无伤大雅的卡通轻敲，接触时发出"DUANG"一声轻金属响加一声卡通弹簧声。旺财头顶弹起一个扁平红色卡通肿包，纸片身体垂直弹跳一次、眼睛瞪大，两只贴纸爪抱住头。右手随后把锅铲收回锅中，左手保持缺席。不得有力度感，不得出现受伤、燃烧等写实痛苦表现。 |
| 5～8秒 | 喂食 | 同一只右手与同一把锅铲保持可见。旺财双眼变成扁平螺旋卡通眼，两股亮蓝色 2D 贴纸眼泪喷泉从眼侧喷出。右手用锅铲从辣粉上舀一小口，送到旺财张开的卡通嘴边，食物轻轻"boop"一声弹进它的嘴里；它的脸颊立刻鼓成两个暖红橙色的圆形贴纸气球；哭声夸张卡通化，锅铲在辣椒面里轻轻刮动。不得出现哽咽、呛咳、灼伤等真实痛苦表现；不出现第二只手。 |
| 8～9.7秒 | 辣翻 | 旺财咽下食物，扁平身体瞬间泛成亮红橙色并冻结半拍；眼睛变成两个扁平螺旋热晕圈；张开的小嘴里喷出一小团扁平 2D 贴纸火焰（像迷你龙息），耳朵里冒出两缕扁平白蒸汽；随后它像一张轻纸片似的向后翻下塑料矮凳，短四肢朝上、一只贴纸爪还在扇嘴；头顶肿包周围旋转一圈扁平卡通红辣椒，鼻尖飘起一缕扁橙色蒸汽；伴随短促的"咝"声、纸片般的轻"噗"落地声与滑稽的下滑哨音；翻倒过程中毛发、项圈、衣服、贴纸白边、圆肚皮全程保持一致。翻倒不得出现 3D 体积感，不得出现写实坠落。 |
| 9.7～10秒 | 收束 | 清晰定格在最终视觉笑点上（旺财仰面躺地、双眼螺旋、火焰微光），结束全片。 |

## 5. 硬性规则

- **一次只出现一只实拍手**——画面中恰好一只实拍手可见，且绝不与另一只手同框。
- **手部分工**——左手绝不炒粉、右手绝不端罐；左手绝不碰锅铲；实拍手绝不帮旺财倒辣椒。
- **完全扁平的贴纸**——旺财必须保持完全扁平 2D 贴纸质感：无 3D 体积、无写实毛发、无体积光、无塑料深度、无黏土质感、无写实投影，仅以轻微扁平卡通方式压扁或拉伸；角色身上无文字、数字、Logo、首饰与额外配件。
- **一镜到底**——固定宽幅构图、仅轻微手持漂移，无切镜、无转场、无变焦、无大幅重新构图。
- **全片无声对白**——任何位置无对白。

## 6. 不想要（反向约束）

贴纸出现 3D 体积或写实毛发 / 阴影 / 黏土质感；任一画面两只实拍手同框；两只左手、两只右手；重复手臂；多余手掌；第二把锅铲；一把在锅内一把在空中的穿帮；左手炒粉；右手端罐；左手碰锅铲；实拍手帮旺财倒辣椒；旺财身上文字 / 数字 / Logo / 首饰 / 额外配件；写实痛苦（哽咽、呛咳、灼伤）；对白。

## 7. 生成

- 模式：T2VA（纯文字生成）——无参考图、无首帧。
- 10s、16:9、24fps、H3 原生音频（食物滋滋、纸片倒落、卡通敲头 / 弹簧、boop、咝、下滑哨音等叙事性音效——无对白）。
