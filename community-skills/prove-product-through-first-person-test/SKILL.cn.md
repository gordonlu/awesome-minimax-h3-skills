# 第一人称实测产品 — UGC 食品测评

当用户想要**真实第一人称 UGC 食品试吃测评**时使用：iPhone 自拍 vlog 质感、手持、自然光、快速跳切、抖音/Reels 审美。中国女孩用普通话在 8 个快速分镜中测评肉夹馍。

核心原则：**每个镜头把产品锁死参考图、保持真实的随意感、把模型的预算花在真实食物与真实测评瞬间——而不是商业摆拍。**

提示词遵循 H3 三段式结构（参考锁定 → 核心创意 → 8 分镜列表带对白），带硬性反向约束。

---

## 1. 触发场景

- 第一人称"实测产品"的食品试吃测评短视频
- 电商 / 社交的 UGC、KOC 风食品测评
- "用真实 vlog 风测评这个食品"

**不要用**这个 Skill 的场景：

- 想要电影级商业食品广告
- 想要专业影棚真人口播
- 没有食品产品参考图

## 2. 输入

- 一张食品产品参考图（`@图片1`）——每个镜头锁定白吉馍形状、卤肉厚度、腊汁状态、配菜与比例。
- （可选）测评者描述：中国女孩、自然美、深色松散马尾、米白卫衣、淡妆、明亮笑容、亲切生活方式博主气质。
- 时长 15s、画幅 16:9、真实 UGC / iPhone 自拍 vlog、普通话对白。

## 3. 分镜列表（8 个，快速跳切）

1. **0–2s** 自拍展示纸袋。她说："夜宵时间！"
2. **2–4s** 打开纸袋取出肉夹馍。
3. **4–6s** 快速推近肉夹馍。
4. **6–8s** 双手拿起肉夹馍，腊汁自然淌下。
5. **8–10s** 咬一口的反应。她说："哇……这个真的绝了。"
6. **10–12s** 随意近景 b-roll：伸手拿酸梅汤喝一口。
7. **12–14s** 把肉夹馍举向镜头干杯。她说："你也得来一个。"
8. **14–15s** 定格帧，叠加文字："肉夹馍 = 快乐 🥙"

## 4. 风格与硬性规则

- 手持、自然光、轻微颗粒、自动对焦呼吸感、手持不完美、快速跳切。不做电影感调色、不做影棚光、不做商业摆拍。
- 食物忠实参考图：不做 CGI 肉夹馍、不做假汤汁、不做手部扭曲、不做食物变形、不做 Logo 畸变。
- 对白只用普通话。

## 5. 生成

- 模式：I2VA，`@图片1` 仅作产品参考——除非明确要求，不作为首帧。
- 15s、16:9、H3 原生音频（人声 + 环境声）。

## 6. 已验证成片

使用打包 prompt + 参考图在 MiniMax H3 端到端生成了一条 15.08s / 1376×768 / 24fps 的 MP4。预览：`assets/preview.mp4`，海报：`assets/poster.webp`，产品参考图：`assets/reference.png`。
