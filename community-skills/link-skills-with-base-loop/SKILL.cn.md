# 技能联动 · 基础循环 — 角色设定展示图

当用户想要从单张角色参考图构建一张**杂志级角色设定展示图**时使用：英雄主视觉 + 细节网格 + 三视图 + 配色板 + 名牌，以近乎静止的 4 秒镜头呈现，只保留极轻微的生命感动态。

核心原则：**角色锁死参考图、画面保持静止、把模型的预算花在印刷级细节与版式上——而不是运动。**

提示词遵循 H3 三段式结构（参考锁定 → 核心创意 → 近静态镜头描述），带严格反向约束。

---

## 1. 触发场景

- 游戏 / 动漫 / 系列作品的角色设定图、设定展示板
- 从一张图"设计这个角色的参考板"
- 静态或近乎静态的角色介绍卡

**不要用**这个 Skill 的场景：

- 想要动画场景、打斗或故事片段
- 想要真人摄影质感（本 Skill 是赛璐璐 3D / 半写实 CGI，非摄影）
- 没有角色参考图

## 2. 输入

- 一张角色参考图（`@图片1`）——锁定脸、体型、比例、发型、肤色与服装，不重新设计。
- （可选）角色名与文案行（名牌 + 标语）放置于版面上。
- 时长 4s、画幅 16:9、近静态，仅极轻微呼吸感动态。

## 3. 版面布局（自左向右）

- **左侧 / 英雄主视觉**：角色全身 hero 动态造型，风格化水墨或纯色背景向白底淡出；左上角大字名牌，下方小字标语。
- **右栏**：`DETAILS`——4 个特写格（平静的脸、专注的双眼、衣领与腰带结法、木地板上赤足）；三视图 `TURNAROUND`（正面 / 侧面 / 背面，同人同装同比例，含独立小道具插图）；配色板 `PALETTE`（白、墨黑、朱砂红、竹青等按设计）；右下角小标语。

## 4. 风格与动态

- 赛璐璐 3D 动漫、半写实 CGI、手绘质感、硬边笔触。不是卡通、不是迪士尼、不是皮克斯。印刷级细节。
- 近静态：仅 hero 的衣摆、发丝与泼墨边缘有极轻微呼吸感动态。无镜头移动、无大幅运动、无第二人物。
- 无字幕动画、无额外文字出现、无动态海报变换。

## 5. 生成

- 模式：I2VA，`@图片1` 仅作角色参考——除非明确要求，不作为首帧。
- 4s、16:9、H3 原生音频（近静态展示无需配乐）。

## 6. 已验证成片
