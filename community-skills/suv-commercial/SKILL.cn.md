# 豪华 SUV 广告 — 未来奢华汽车广告

当用户需要一条**未来豪华 SUV / 汽车广告**、必须优雅昂贵克制真实、如国际豪华汽车品牌正式商业片时使用。从一张车辆参考图生成一段连续 15 秒成片（16:9、24fps、电影质感）。

核心原则：**车辆锁死参考图、全片左舵一致、把模型的预算花在克制与真实上——绝不花在科技 Demo 噱头上。**

提示词遵循 H3 三段式结构（参考锁定 → 核心创意 → 带时间码的分镜表），带严格反向约束。原始 prompt 由 Flkrstudio 创作，此处打包为可复用 Skill，附带一条已跑通的 15 秒成片。

---

## 1. 触发场景

- 未来豪华 SUV / 汽车广告、展厅电影、设计工作室品牌片
- "要像真正的豪华汽车品牌广告"——昂贵、安静、电影感
- 新车发布 / 旅程开始：女司机、内饰细节、氛围灯、前灯点亮的完整流程

**不要用**这个 Skill 的场景：

- 要科技 Demo / 科幻 HUD 堆满的车拍——那是另一种视觉语言
- 要赛车游戏式的动态追车
- 没有车辆参考图（本 Skill 围绕锁定单张车辆参考图构建）

## 2. 输入

- 一张车辆参考图（`@图片1`）——车辆的**唯一**参考：车身比例、四门、玻璃、轮毂、轮胎、前后灯、保险杠、侧面线条与内饰全部锁定，禁止重新设计，禁止第二套内饰。
- （可选）女司机文字描述：成年女性、相同脸、蓝灰色眼睛、深色长发、真实肤质、黑色高级极简服装。动作自然自信从容——不要走秀、不要看镜头、不要摆 Pose。
- 时长 15s、画幅 16:9、24fps、电影级（4K 质感）。

## 3. 硬性规则

### 车辆锁定
车身比例、四门、玻璃、轮毂、轮胎、前后灯、保险杠、侧面线条、内饰——全部来自 `@图片1`。车牌只写：家越07。绝不重新设计车辆，绝不生成第二套内饰。

### 左舵最高优先级
方向盘固定左侧；驾驶员始终坐左前座、副驾在右、Center Console 始终在两前座之间正中；女司机必须从左前驾驶门进入。任何 Interior Shot：禁止镜像、禁止右舵、禁止中控乱位、禁止内饰翻转、禁止第二套内饰。

### 环境
夜间未来主义 Brutalist 私人汽车设计馆：深灰混凝土、黑色石材、垂直 Platinum 灯带、抛光黑色反射地面、轻微电影雾。色彩仅限：Obsidian Black / Gunmetal / Platinum / Cool White / 少量 Warm Amber。启动后车内允许低亮度细腻深蓝 Ambient Light——不是蓝色霓虹。禁止 Cyberpunk RGB、紫粉灯、广告牌和随机文字。

### 字体（Typography）
现代 Luxury Sans Serif，细字重、宽字距、Ivory White / Soft Platinum、大量负空间。动画统一：Soft Fade In 6–10 帧 → Hold → Soft Fade Out 6–10 帧，仅允许轻微字距展开和 2–3% 微位移。禁止巨大文字、Fly-In、Glitch、HUD、弹跳、快速旋转。

### 只允许文字（仅这五组）
1. SCULPTED AERODYNAMICS / ELEGANCE IN MOTION
2. FULL-GRAIN NAPPA LEATHER / TAILORED COMFORT
3. ADAPTIVE AMBIENT LIGHT / SIGNATURE BLUE
4. PANORAMIC GLASS ROOF / OPEN TO THE NIGHT
5. ROEWE 家越07 / THE JOURNEY BEGINS

### NO BGM
绝对不要背景音乐、歌曲、鼓点、电子音乐、旁白、对白、人声。只保留高级电影 SFX：脚步、手掌轻触车漆、门把手机械声、豪华车门开启与厚重关闭、皮革与衣料摩擦、启动按钮 Click、仪表与中控启动电子声、Ambient Light 系统声、电驱系统低沉启动、轮胎开始滚动、车辆经过空间的空气声、大型 Brutalist 建筑自然混响。所有声音严格同步。
