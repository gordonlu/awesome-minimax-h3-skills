# 不完美记忆直录 — 1998 年滨海小站 MiniDV 送别

当用户想要一条**像被遗忘的老摄像机磁带一样的记忆式影片**时使用：1998 年秋天滨海小站的安静送别，透过 90 年代 MiniDV 家庭录像那台不完美、不稳的镜头去看。

核心原则：**不完美就是媒介——剧烈手持抖动、失焦、漂移的曝光与压缩痕迹就是质感；绝不让它看起来稳定、现代或构图工整。**

提示词遵循 H3 带时间码结构（核心创意 → 五段式画面过程描述，每拍含正向与反向约束 → 硬性反向清单）。仅 T2VA——纯文字，无参考图。

---

## 1. 触发场景

- "原始素材 / 老摄像机磁带"记忆影片
- 火车站（或类似的安静送别）怀旧告别
- "要像真正的 90 年代家庭 MiniDV 录像"
- 需要真实年代摄像机质感的回忆 / 闪回场景

**不要用**这个 Skill 的场景：

- 要平滑、电影感、防抖的镜头——本 Skill 必须看起来晃动、手持
- 要现代手机画质、清晰对焦加滤镜
- 要音乐或旁白——只允许环境声
- 需要参考图驱动画面（本 Skill 是纯 T2VA）

## 2. 输入

- 仅文字场景描述：镰仓一座滨海小站，1998 年秋天；20 岁日本女生、日常素颜模样；在月台等车、看海、上车前挥手告别。
- 时长 15s、画幅 16:9、24fps、超写实纪录片风格，穿戴完整 90 年代 Sony MiniDV 摄像机质感。
- 无参考图、无首帧——T2VA。

## 3. 核心创意

15 秒、16:9、超写实纪录片风格短片。一段被遗忘的 1998 年秋天 MiniDV 家庭录像，记录镰仓一座滨海小站宁静的早晨。主角是 20 岁日本女生、日常素颜模样，在月台等车、看海、上车前挥手告别。全片穿戴 90 年代 Sony MiniDV 摄像机质感——剧烈手持抖动、构图不准、自动对焦在电车与她的脸之间来回拉、曝光随日光起伏、色彩褪色、对比柔和、轻微运动模糊、MiniDV 压缩痕迹、无防抖——按时间分段普通切镜。

## 4. 画面过程描述

| 时间 | 节拍 | 必须发生的内容 |
|---|---|---|
| 0～3秒 | 建立 | 她站在月台边缘，手捧一杯温热的站台热茶，望向远处的铁轨。镜头先短暂对焦到站台指示牌上，再找到她的脸；轻风拂过她的发梢。不要稳定平滑的镜头，不要现代手机拍摄质感。 |
| 3～6秒 | 犹豫 | 凉爽海风吹过她的头发，她低头查看站台时刻表，轻轻笑了一下；操作者无意中推得太近，又慌忙拉回来修正。不要精致摆拍，不要稳准快的对焦。 |
| 6～9秒 | 等候 | 她坐在月台木椅上喝了一口热茶，望向大海；自动对焦在她侧脸与身后闪光的水面之间来回切换。不要补光、不要滤镜感。 |
| 9～12秒 | 电车进站 | 电车缓缓进站，传来柔和的金属轰鸣；她起身、整理肩上的帆布包，走向打开的车门。不要车窗玻璃映出明显的后期痕迹。 |
| 12～15秒 | 送别 | 上车前她注意到摄像机，对着镜头小小地挥手、微笑，随即走进车厢；车门开始关闭，镜头缓缓下移，录像戛然切黑。不要摆拍感，不要字幕。 |

## 5. 硬性规则

- **全程 90 年代 MiniDV 摄像机质感**——剧烈手持抖动、构图不准、自动对焦在电车与她脸之间来回拉、曝光随日光起伏、色彩褪色、对比柔和、轻微运动模糊、MiniDV 压缩痕迹、无防抖。
- **身份一致性**——她的脸、服装与发型全片保持一致。
- **只保留环境声**——无音乐、无旁白，只保留自然环境声（海浪、海鸥、轻风、远处车站广播、脚步声、电车刹车、车门开合、低声交谈）。
- **画面无任何文字**——画面干净。
- **普通切镜**——按时间分段的普通切镜，不是现代精致剪辑。

## 6. 不想要（反向约束）

稳定器画面；现代手机拍摄质感；清晰、稳准快的对焦；精致摆拍；补光；滤镜感；音乐；旁白；画面任何文字；车窗玻璃映出明显后期痕迹；身份、服装、发型改变；现代精致剪辑感。
