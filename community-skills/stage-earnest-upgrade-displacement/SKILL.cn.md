# 升级讽刺｜新物登场旧爱被移走 — 1950 AMBER MIND 电视广告

当用户想要一段**15 秒 1950 年代三段式染印法（Technicolor）电视广告**、且必须像真正的中世纪真人实拍广告时使用：明亮温暖的氛围里，一家人升级他们心爱的旧思考机器 TRITON 到更大的 TITAN——而死死抱住旧机器不放的小男孩被拖过抛光地板。

核心原则：**用完全的真诚去卖"升级"这件事、机位锁定而正式（三脚架 + 一次缓慢推轨，恰好 4 次硬切），让每一层 1950 质感——染印法饱和、暖高调光、镀铬、胶片颗粒、单声道光学声带暖感——承载时代氛围。**

提示词遵循 H3 三段式结构（核心创意 → 带时间码的 BEATS + 音频 → 严格反向约束）。T2VA：纯文字生成，无参考素材。

- **0～3.5 秒（机位锁定的全景，硬切开场）**：锃亮的 1950 年代电器展厅，一家人整齐站成一排（父亲 38 岁灰色西装、母亲 35 岁束腰蓝裙 + 药盒帽、女儿 11 岁黄裙、男孩 7 岁短裤 + 蝴蝶结 + 侧分头），围在矮台上的 TRITON 前欣赏：奶油搪瓷 + 黄铜机身、顶部一只圆形琥珀玻璃眼缓慢眨动；全家真挚热切，女儿双手抱拳托在颌下；展厅安静环境声、机器轻柔电嗡，琥珀眼每次眨动伴随一声柔和继电器咔嗒。画面无任何文字，无字幕无 Logo；不要手持晃动、不要变焦。
- **3.5～6.5 秒（硬切中景）**：男孩上前一步，双臂环抱 TRITON，脸颊贴上搪瓷外壳；机器琥珀眼缓缓眨一下，仿佛很满意；他手里不拿任何别的东西。画面无任何文字；不要男孩表情夸张。
- **6.5～10 秒（硬切锁定的全景）**：两名藏蓝工装 + 平顶帽工人推着更庞大、更闪亮、双琥珀眼 + 前脸镀铬饰条的新款 TITAN 从画面左侧进场，随即把 TRITON 推向画面右侧；男孩仍抱着机器，双脚在抛光地板上滑出几英尺，表情只是轻微困惑，绝不痛苦；6.8 秒处手推车轮碾过抛光地板，随后小鞋在木地板上滑动。男孩不哭不慌；画面无任何文字；工人只推车不拿别的东西。
