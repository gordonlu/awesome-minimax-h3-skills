# 单目标逃生｜前后灾害交替逼近 — 火墙逃生奔跑

当用户想要一条**写实灾难动作、单一连续镜头的场面**时使用：主角在工业走廊中朝一个明确目标狂奔，火焰与碎物不断切断前方通路、封死身后退路。

核心原则：**一个目标、一条故事线、一个连续镜头——动作快而清晰，绝不慢动作、绝不切镜、绝不平稳广告式构图。**

提示词遵循 H3 带时间码结构（核心创意 → 三段式画面过程描述，每拍含正向与反向约束 → 硬性反向清单）。仅 T2VA——纯文字，无参考图。

## 1. 触发场景

- 灾难动作 / 逃生场面：某人在工业或科幻走廊中躲避蔓延的大火或危险物
- "一个目标、一条故事线、一镜到底"的电影感奔跑
- 紧急封舱 / 防爆闸板高潮：主角压下巨大拉杆，将防爆闸板合拢在自己与大火之间
- 工业科幻室内：反应堆舱室、货船走廊、喷出的蒸汽、频闪的红色应急灯

**不要用**这个 Skill 的场景：

- 要平稳、广告式、构图工整的镜头——本 Skill 是原始、紧迫的手持感
- 要卡通 / 风格化的灾难——本 Skill 是写实工业质感
- 要慢动作或面部特写剧情——两者皆被禁止
- 需要参考图驱动画面（本 Skill 是纯 T2VA）

## 2. 输入

- 仅文字场景描述：星际货运飞船反应堆舱室、狭窄金属通道、身穿工作服的女机师、红色应急照明、地板格栅喷出炽红燃料火浪、破损管线爆裂火星四溅。
- 时长 15s、画幅 16:9、24fps、写实灾难动作质感、单一连续不间断镜头。
- 无参考图、无首帧——T2VA。

## 3. 核心创意

15 秒、16:9、写实灾难动作片。星际货运飞船的反应堆舱室内，一名女机师独自在狭窄金属通道上狂奔，冲向前方的紧急封舱控制台；炽红燃料火浪不断从地板格栅喷出，管线爆裂火星四溅。现实工业质感、红色紧急照明、快而清晰的动作节奏、一个目标一条故事线、一镜到底无切镜。

## 4. 画面过程描述（单一连续镜头）

| 时间 | 节拍 | 必须发生的内容 |
|---|---|---|
| 0～4秒 | 低角度大全景，正向 | 舱室低角度全景：蒸汽弥漫、红色警示灯频闪、金属管道震颤、破损管线喷出火花。女机师沿通道奔跑，身后第一股炽红燃料火浪从格栅下喷涌而出，火、火星与碎屑飞溅。她继续前冲；前方通道又被火浪撕开，她被迫贴护栏侧身绕行；头顶一段粗管道砸落身后，退路被封死。不要平稳广告式构图、不要卡通化、无字幕无 Logo、不出现面部特写。 |
| 4～9秒 | 贴身侧面跟拍 | 镜头贴身侧面跟拍。她弯腰躲过一股白色蒸汽，踩到灰烬打滑、撞上护栏、重新站稳继续前冲；更多火浪从地板猛烈喷出。动作始终清楚有力、快而不糊。不要慢动作，不出现第二个主要人物。 |
| 9～15秒 | 正面推进至收束 | 她冲到紧急封舱控制台前（控制台位于舱室一侧的安全区），火浪正从身侧破开格栅涌出。她整个身体压上巨大的封舱拉杆将其压下；厚重防爆闸板沿滑轨开始在她身后、火浪与她之间轰然合拢；头顶泄压阀爆开，舱室被蒸汽灌满。最后一镜：她踉跄退后两步，停在闸板内侧的安全区里喘息，防爆闸板在她身后彻底合拢、把她和火浪完全隔开——火浪在闸板外侧撞上金属板溅起炽亮火星，停在几米之外。她必须始终位于闸板内侧；闸板合拢后不得出现她位于闸板外侧、闸门之外或从门外再出现的画面。不要面部大特写，不要慢动作。 |

## 5. 硬性规则

- **一镜到底无切镜**——全片是一个连续镜头。
- **单一主角**——女机师是唯一主角，任何位置不得出现第二个主要人物。
- **始终在安全区内侧**——闸板合拢后女机师必须始终在防爆闸板内侧：绝不出现闸板外侧、绝不出现在门闸之外、绝不从门外再现。
- **动作快而清晰**——每个节拍清楚有力、快速但不糊；禁止慢动作。
- **写实工业质感**——真实反应堆 / 货船材质与红色应急照明；禁止卡通、禁止平稳广告式构图。
- **无面部特写**——把画面放在身体动作与环境上。

## 6. 不想要（反向约束）

画面任何文字或 Logo；卡通风格；多余角色；名人脸；慢动作；平稳广告式构图；闸板合拢后女机师出现在闸板外侧或从门外再现；面部特写；切镜；动作不可读或发糊。
