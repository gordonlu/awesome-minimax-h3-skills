# Alternate Obstacles Toward Goal — Fire-Wall Escape Run

Use this Skill when the user wants a **realistic disaster-action scene with a single continuous take**: a protagonist racing through an industrial corridor toward one clear goal while fire and debris keep cutting the path ahead and sealing the route behind.

Core principle: **one goal, one storyline, one continuous shot — fast and clear action, never slow motion, never cutaways, never stable commercial framing.**

The prompt follows the H3 timecoded structure (core concept → three-segment screen description with positive and negative per beat → hard negative list). T2VA only — pure text, no reference image.

---

## 1. Trigger

Use this Skill when the user's request matches any of:

- A disaster-action / escape sequence: someone fleeing a spreading fire or hazard through an industrial or sci-fi corridor
- "One goal, one storyline, one continuous take" cinematic run
- An emergency-seal / blast-door climax: a protagonist slams a heavy lever to close a blast door between themselves and the fire
- An industrial sci-fi interior: reactor rooms, cargo corridors, venting steam, flickering red emergency lights

Do **not** use this Skill when:

- The user wants a stable, ad-like, smoothly composed shot — this is raw, urgent, hand-held energy
- The user wants cartoon / stylized disaster — this is realistic industrial texture
- The user wants slow-motion or facial close-up drama — both are forbidden
- A reference image must drive the look (this is pure T2VA)

## 2. Inputs

- A text description of the scene only: interior reactor compartment of an interstellar cargo ship, narrow metal corridors, a female flight engineer in a work suit, red emergency lighting, bursts of crimson fuel fire from floor grates and severed pipes.
- Duration 15s, aspect 16:9, 24fps, realistic disaster-action look, one continuous unbroken shot.
- No reference image, no first frame — T2VA.

## 3. Core Concept

15 seconds, 16:9, realistic disaster-action. Inside a star-freighter reactor compartment, a female flight engineer runs alone down a narrow metal corridor toward a forward emergency seal console; crimson fuel-fire waves keep erupting from floor grates and severed pipes burst into sparks. Real industrial texture, red emergency lighting, fast and clearly readable action beats, one goal and one storyline, shot in a single unbroken take with no cuts.

## 5. Hard Rules

- **One continuous shot, no cuts** — the whole film is a single take.
- **Single main character** — the engineer is the only protagonist; no second major character anywhere.
- **Stay inside the safe zone** — the engineer must always be inside the blast shutter after it seals: never shown outside the shutter, never beyond the door, never re-entering from the outside.
- **Fast and clear action** — each beat readable and forceful, quick but never blurry; no slow motion.
- **Realistic industrial texture** — real reactor/cargo-ship materials, red emergency lighting; no cartoon, no stable ad-style composition.
- **No facial close-ups** — keep the action on the body and the environment.

## 6. Negative Rules (Do Not)

Any text or Logo in the frame; cartoon style; extra characters; celebrity faces; slow motion; stable ad-style framing; the engineer appearing outside the blast shutter after it closes or re-entering from outside; facial close-ups; cutaways or cuts; unreadable or blurry action.

## 7. Generation

- Mode: T2VA (pure text-to-video) — no reference image, no first frame.
- 15s, 16:9, 24fps, native H3 audio (diegetic SFX: fire roar, pipe bursts, machinery, steam).
