# 第一视角探险｜穿越后巡检 — 火山学家熔岩管勘察

当用户想要一段**15 秒超写实第一人称科考纪录短片**时使用：清晨 5:30–5:45、薄雾的火山荒原，两名火山学家穿着防滑登山靴、头盔与头灯，钻进一处新形成的熔岩管，在它内部结构进一步变化前记录它。

核心原则：**跨过临界点进入一处仍在变化的自然结构——第一人称的紧迫感混搭第二机位跟拍，头灯在岩壁上扫出移动的光斑，呼吸声与脚步声始终清晰，研究者全程保持冷静专业。**

提示词遵循 H3 三段式结构（核心创意 → 带时间码的分段 → 严格反向约束）。T2VA：纯文字生成，无参考素材。

## 1. 触发场景

- 第一人称探险 / 洞窟考察纪录短片
- "进入一处不稳定结构"的临界穿越场面——进入、检查、撤离
- 真实的科考勘察：火山学家、熔岩管、头灯、测量设备

**不要用**这个 Skill 的场景：

- 想要奇幻、超自然或风格化的洞穴景观
- 想要博物馆式导览或旅游宣传片
- 想要恐慌 / 惊悚反应——本技能保持冷静科学

## 2. 输入

- 纯文字——无参考图（T2VA，纯文字生成）。
- 时长 15s、画幅 16:9、超写实第一人称科考纪录。
- 主体：两名火山学家，防滑登山靴、头盔、头灯、紧凑测量设备；环境为薄雾火山荒原上新形成的熔岩管，清晨时刻。

## 3. 分段（带时间码，16:9）

- **0～3 秒（挤入洞口）**：两名研究者从狭窄的洞口侧身挤入；灰白的晨光从洞口透入，头灯光柱在岩壁上扫动。不要空镜拖节奏，保持呼吸声与脚步声清晰可闻。
- **3～6 秒（洞壁展现）**：镜头揭示环绕四周的深色玄武岩壁与玻璃质火山岩层，光在岩壁表面自然漫射；质感是真实坚实的火山岩，而不是人造道具。不要奇幻造型、不要超自然元素。
- **6～9 秒（异动发现）**：一名研究者注意到管壁裂缝中突然有热气与水滴渗出，镜头给出岩缝间水汽流动的细节，两人停下观察。不要不可能的洞穴几何。
- **9～12 秒（后退检查）**：两人小心地后退一步，蹲下检查正在变化的地表；头灯光斑缓缓扫过岩层，碎石在脚下轻微滑落。不要恐慌反应，保持冷静专业的科考姿态。
- **12～15 秒（标记撤离）**：他们标记好这个位置，开始向透进晨光的洞口退去，画面朝亮处移动，收束在洞口的光里。不要突然加速离场，无字幕无 Logo。

## 4. 硬性规则

- 岩壁质感必须像真实坚实的火山岩，而不是人造道具。
- 光线必须在洞壁表面自然漫射；只允许头灯与晨光。
- 无奇幻造型、无超自然元素、无不可能的洞穴几何。
- 无文字、无字幕、无 Logo。
- 全程冷静专业的科考姿态——无恐慌。
- 声音：登山靴踩碎石声、滴水声、岩壁深处的闷响、呼吸声、压低的说话声。
