# CCD 取景器记忆｜2009 校园 vlog

当用户想要一段**15 秒 4:3 怀旧 CCD 相机记忆短片**、且质感像从旧存储卡里翻出来的录像时使用：一位年轻东亚女生（柔软波浪长发、暖色肤色、深棕眼睛、左眼下小痣、淡妆、黑色细肩带背心、随意搭在肩上的宽松白开衫、浅蓝牛仔裤）自拍着走过 2009 年的校园——图书馆、漫画书架、楼梯、玻璃走廊、户外校区、商场书店、店铺玻璃——用中文轻声对镜头说话，最后挥手、REC 图标闪烁切黑。

核心原则：**观众始终看到暗室里一台口袋数码相机亮着的 LCD 取景器**——屏幕边缘向黑暗与模糊淡出，而持续的相机 UI 叠加层（REC、对焦框、电池、时间戳、曝光读数）始终留在画面上。刻意保留不完美：直闪硬光、皮肤轻微过曝、柔颗粒、压缩伪影、LCD 像素纹理、轻微白平衡偏差、偶发自动对焦搜索。

提示词遵循 H3 三段式结构（核心创意 → 带时间码的分镜 → 严格反向约束）。I2VA：一张角色参考图（锁定女生的脸 / 身材 / 服装），仅作参考（不作为首帧）。

## 适用场景
- 怀旧记忆 / 家庭录像 / "被翻出的素材" 质感
- 2000 年代初 CCD / Cyber-shot 卡片机观感
- 任何"相机 UI 与不完美本身就是风格"的需求

## 硬性规则
- 角色的脸、身材、发型、年龄与服装在 8 个节拍中完全一致（不重新设计）。
- 持续在屏 UI：REC 图标、对焦框、电池、时间戳 "8.1.2009 3:15 AM"、"1/30 F3.4 ISO100"——并保留可见的 LCD 眩光与真实屏幕纹理。不出现任何其他文字。
- 拥抱不完美：手持晃动、自动对焦搜索、白平衡偏差、颗粒、压缩。
- 无字幕、无配乐、除画面内轻声中文台词外无旁白。
