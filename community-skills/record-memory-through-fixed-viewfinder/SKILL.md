# CCD Viewfinder Memory — 2009 Campus Vlog

Use this Skill when the user wants a **15-second 4:3 nostalgic CCD-camera memory short** that feels like footage recovered from an old memory card: a young East Asian woman (soft wavy hair, warm skin, dark-brown eyes, small mole under the left eye, light makeup, black thin-strap tank top, white cardigan draped over her shoulders, light-blue jeans) films herself walking through a 2009 campus — library, manga shelf, stairs, glass corridor, outdoor quad, mall bookstore, shop window — talking softly to camera in Chinese, then waves and the REC icon blinks to black.

Core principle: **the viewer always sees the glowing LCD viewfinder of a pocket digital camera in a dark room** — screen edges fade to dark and blur, while a persistent camera UI overlay (REC, focus box, battery, timestamp, exposure readout) stays on screen the whole time. Keep the look imperfect on purpose: direct-flash hard light, slight skin overexposure, soft grain, compression artifacts, LCD pixel texture, slightly wrong white balance, occasional autofocus hunting.

The prompt follows the three-part H3 structure (core concept → timecoded beats → hard negative rules). I2VA: one character reference image (locks the woman's face/body/outfit), used only as reference (never as the first frame).

- Any brief where the camera UI and imperfections ARE the style

## Hard rules
- The character's face, body, hair, age and outfit stay identical across all 8 beats (no redesign).
- Persistent on-screen UI: REC icon, focus box, battery, timestamp "8.1.2009 3:15 AM", "1/30 F3.4 ISO100" — and keep visible LCD glare/texture. No other text ever.
- Embrace imperfections: handheld shake, autofocus search, wrong white balance, grain, compression.
- No subtitles, no music bed, no narration beyond the soft in-scene Chinese lines.
