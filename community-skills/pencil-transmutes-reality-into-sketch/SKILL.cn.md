# 铅笔将现实转化为素描 — 香港魔法铅笔

当用户想要一条**魔法铅笔短片**时使用：手执铅笔指向真实的移动主体，把它们一个接一个完全变成 2D 手绘动画，而主体仍在自然运动，背景是一座明亮真实的都市。

核心原则：**彻底且同步的转化——主体一入画铅笔立刻动笔，结果完全手绘、零实拍残留；绝不半途、绝不迟滞、绝不蔓延到环境。**

提示词遵循 H3 带时间码结构（核心创意 → 四次转化的画面过程描述，每拍含正向与反向约束 → 硬性反向清单）。仅 T2VA——纯文字，无参考图。

---

## 1. 触发场景

- "魔法铅笔"/"铅笔指到什么都变成素描"的效果
- 实拍转动画的跨媒介转化短片
- 真实城市环境中的 POV 涂鸦魔杖视频
- 多主体顺序转化的展示片（列车、猫、出租车、人）

**不要用**这个 Skill 的场景：

- 要全场景动画化——环境必须保持写实，只有被指的主体转化
- 要转化缓慢、半途、或主体已在画面上出现一段时间后才动笔
- 要转化时定格 / 冻结、或镜头跳动
- 需要参考图驱动画面（本 Skill 是纯 T2VA）

## 2. 输入

- 仅文字场景描述：明亮写实的香港——港铁站台、有街猫的旧唐楼窗台、霓虹招牌林立的闹市街道、有长椅的公园；一只手握一支橙色铅笔在这些地点移动。
- 时长 10s、画幅 16:9、24fps、POV 魔法铅笔电影质感。
- 无参考图、无首帧——T2VA。

## 3. 核心创意

10 秒、16:9、POV 电影风格魔法铅笔短片。一只手握一支橙色铅笔，笔尖指向现实世界中的移动主体，将它**彻底**转化为动画化 2D 手绘插图、同时保留其自然运动。转化必须是完全的：主体实拍的颜色、材质与光影质感全部消失，完全由铅笔线条构成，不留任何实拍痕迹。**转化必须与主体出现同步：主体一进入取景，铅笔立刻指向它并开始勾线，不允许主体先出现一段时间后才动笔。**依次转换四组主体：驶过香港地铁站的港铁列车、旧唐楼窗台上的橙色虎斑猫、行经闹市街道的红色出租车、坐在公园长椅上的女性。明亮逼真的香港城市环境、流畅的转换、魔法铅笔效果、全程一致的摄像机运动、无缝的实拍转动画转化。

## 4. 画面过程描述

| 时间 | 节拍 | 必须发生的内容 |
|---|---|---|
| 0～2.5秒 | POV 建立 + 港铁列车 | POV 镜头，手持橙色铅笔从画面一侧进入，笔尖指向远处驶来的港铁列车（蓝绿色与白色相间）。列车一进入取景铅笔立即落笔，铅笔沿车身快速划过，所过之处列车**完全**变成黑白铅笔素描：车身蓝绿色全部消失，只剩清晰铅笔勾线与密集排线、白色纸面质感，无任何残留实拍颜色；列车保持原速行驶的滚动与晃动。明亮阳光下的香港地铁站台环境保持真实，可见站牌与来往乘客。不要转换卡顿成定格，不要只勾轮廓而保留颜色，不要半实拍半素描的混合状态，不要让列车先出现片刻后才开始转化。 |
| 2.5～4.5秒 | 唐楼街猫 | 镜头平稳平移，铅笔指向旧唐楼窗台上打盹的橙色虎斑猫。猫一入画铅笔立即开始勾线，猫被**完全**转化为白色铅笔素描：橙色皮毛全部消失，皮毛与斑纹完全由密集铅笔排线与纸白构成，只有眼睛保留一点灰铅深浅变化；猫保持伸懒腰、甩尾的自然动作。不要改变猫的动作，不要让转换蔓延到猫以外的物体，不要残留橙色，不要猫出现后才开始转化。 |
| 4.5～6.5秒 | 红色出租车 | 铅笔指向驶过的香港红色出租车，车一入画铅笔立即落笔，车身在行驶中**完全**转化为粉彩粉红色与薄荷绿的卡通艺术：红色漆面全部消失，车身完全由平涂粉彩与卡通勾线构成；车轮继续滚动、车影继续移动；街边霓虹招牌与行人依然明亮写实。不要卡通背景，不要车轮变形，不要残留红色漆面，不要车开过一半才开始转化。 |
| 6.5～8.5秒 | 公园长椅女性 | 铅笔指向坐在香港公园长椅上的女性，她一入画铅笔立即开始勾线，她连同长椅被**完全**转化为风格化的平面色彩动画：皮肤与衣物的写实质感全部消失，完全变为平涂色块与简洁勾线，只有色块深浅层次；保持翻书、整理衣角、风吹发丝的自然小动作。不要面部扭曲，不要转换后人物僵住，不要残留写实皮肤与布料质感，不要她坐定片刻后才开始转化。 |
| 8.5～10秒 | 收尾 | 铅笔尖轻轻画出一个魔法圈，四个已转化主体依次亮起轻微纸面光泽；铅笔收回画面外，镜头缓缓拉远定格：香港的写实环境中点缀着四处 2D 手绘动画，自然运动仍在继续。不要添加文字、不要出现第二支笔。 |

## 5. 硬性规则

- **彻底转化**——被指主体失去全部实拍颜色、材质与光影质感，结果完全手绘；绝不留"半实拍半素描"中间态，转化后绝不留任何实拍颜色与材质。
- **同步转化**——主体一入画铅笔立即开始勾线；绝不允许主体先出现、之后再被画；不得迟滞、不得晚动笔。
- **转化只落在主体上**——只作用于铅笔所指的主体，绝不蔓延到环境；无卡通化背景。
- **保留自然运动**——转化后的主体继续自然运动（车轮滚动、猫伸懒腰、翻书等）；不得冻结、卡顿成定格。
- **摄像机一致**——全片摄像机运动保持同一、平滑；无跳切；无文字；无第二支笔。

## 6. 不想要（反向约束）

画面任何文字或 Logo；转换卡顿、定格或跳跃切换；转换蔓延到环境；转换后主体失去自然运动；任何主体停留在"半实拍半素描"中间态；转化后残留任何实拍颜色与材质质感；主体出现后才开始转化（迟滞）；跳切或摄像机运动不一致；卡通化背景；多余角色；第二支笔。
