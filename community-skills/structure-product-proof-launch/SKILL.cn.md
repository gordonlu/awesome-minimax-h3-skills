# 结构化的产品发布证明 — 旗舰发布广告（h3skills.com）

当用户想要**能量持续升高的 9 连硬切旗舰级产品发布广告**、品牌为 **h3skills.com / H3SKILLS** 时使用——深海军蓝近黑底、电光青、炽白文字、发光粒子贯穿每一帧。

核心原则：**视觉语言锁死参考图、文字始终锐利精确、把模型的预算花在持续升高的能量与昂贵的未来感上——绝不小气、绝不杂乱、绝不复古。**

提示词遵循 H3 三段式结构（参考锁定 → 核心创意 → 9 连镜），含锁定字符串列表与硬性反向约束。

---

## 1. 触发场景

- 旗舰产品 / 平台发布广告
- "GOING LIVE / LAUNCHING NOW" 品牌片
- 科技旗舰风、带品牌字符串的高能推广片

**不要用**这个 Skill 的场景：

- 想要平静、极简或有机美学
- 想要复古或低保真质感
- 没有风格 / 构图参考图

## 2. 输入

- 一张风格 / 构图参考图（`@图片1`）——提供视觉语言：深海军蓝近黑底、电光青、炽白文字、发光粒子质感与字标排版气质。9 个镜头的具体画面按文字描述生成，同时保持该视觉语言。
- 时长 15s、画幅 16:9。

## 3. 品牌字符串（锁定，拼写精确）

`h3skills.com / One Prompt. Endless Shots. / Every Mode. One Prompt. / T2VA · I2VA · FL2VA · L2VA · Ref2VA / Precise Shot-Timed Prompts / Production-Ready Skills / For Creators. By Creators. / GOING LIVE / Ads / Films / Music / Games / LAUNCHING NOW / H3SKILLS`

不出现任何其他数字、字幕、演职员表或文字；无故事板网格、白色说明条或编号标题。

## 4. 九连镜（15s，能量持续升高，硬切）

1. **0–2s** 画面中央向外炸开青色冲击波，穿过粒子与光蝶；h3skills.com 字标完整砸落，其下 "One Prompt. Endless Shots." 亮迹划过写出。硬切。
2. **2–3.6s** 玻璃面板从景深飞出并锁定排布，每块落定带柔和折射光闪；面板内容为活动影像；标题整句落定。硬切。
3. **3.6–4.8s** 圆角组合标点燃，发光描边连续一笔画完四角；深蓝星云后光蝶漂过。硬切。
4. **4.8–6.4s** 浮动剪辑界面在纵深组装：工具轨左滑入、时间线向右延伸、片段缩略图依次填入、高亮框吸附片段；镜头沿玻璃表面轻微漂移。硬切。
5. **6.4–8.2s** 全速：青色光条以最大速度掠过镜头，头发飞扬，粒子撕裂画面；镜头硬而快地推进；标题运动中落定。全片能量峰值。硬切。
6. **8.2–9.6s** 地平线上炸开白色光爆，GOING LIVE 巨大完整铺满画面。硬切。
7. **9.6–11.2s** 五张竖版内容卡依次飞入锁定成一行，每张落定带青色边缘光闪；标题落在上方。硬切。
8. **11.2–12.8s** 四宫格瞬间就位，每象限按各自节拍落定、标签完整落地；四格同播活内容。硬切。
9. **12.8–15s** 粒子向中心汇聚；h3skills.com 与 H3SKILLS 落定；LAUNCHING NOW 药丸按钮点燃，发光描边一笔画完并转为稳定脉动；最后一秒一切静止锐利。

## 5. 硬性规则

- 文字始终锐利完整、满不透明、位置精确。无模糊、重影、半透明、缩放、淡出、位移或运动模糊；无字幕水印角标；无全画面镜头光斑、无 RGB 错位、无胶片颗粒、无黑边、无玻璃描边外文字。
- 高级、快速、昂贵、未来感；绝不小气、绝不杂乱、绝不复古。
- 配乐：原创高能科技发布配乐（深层次低音、硬质合成打击、爬升琶音、宽失谐铜管、颗粒 riser、一次巨大冲击音）；无旁白无人声。

## 6. 生成

- 模式：I2VA，`@图片1` 仅作风格参考——除非明确要求，不作为首帧。
- 15s、16:9、H3 原生音频。
