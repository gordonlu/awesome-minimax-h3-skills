# Structure Product Proof Launch — Flagship Launch Ad (h3skills.com)

Use this Skill when the user wants a **flagship product-launch ad** with an escalating 9-hard-cut structure, branded with **h3skills.com / H3SKILLS** — deep navy-black base, electric-cyan, incandescent-white text, glowing particles on every frame.

Core principle: **lock the visual language to the reference, keep the text razor-sharp and exact, spend the model's budget on escalating energy and expensive futurism — never cheap, messy or retro.**

The prompt follows the three-part H3 structure (reference locking → core concept → 9-shot list) with a locked string list and hard negative rules.

---

## 1. Trigger

- A flagship product / platform launch commercial
- A "GOING LIVE / LAUNCHING NOW" brand film
- A tech-flagship style high-energy promo with brand strings

Do **not** use this Skill when:

- The user wants a calm, minimal or organic aesthetic
- The user wants a retro or lo-fi look
- No style/composition reference image exists

## 2. Inputs

- One style/composition reference image (`@图片1`) — provides the visual language: deep navy-black near-black base, electric-cyan, incandescent-white text, glowing-particle texture and wordmark typesetting. The 9 shots' exact pictures follow the text description while keeping that visual language.
- Duration 15s, aspect 16:9.

## 3. Brand Strings (locked, spelled exactly)

`h3skills.com / One Prompt. Endless Shots. / Every Mode. One Prompt. / T2VA · I2VA · FL2VA · L2VA · Ref2VA / Precise Shot-Timed Prompts / Production-Ready Skills / For Creators. By Creators. / GOING LIVE / Ads / Films / Music / Games / LAUNCHING NOW / H3SKILLS`

No other numbers, subtitles, credits or text. No storyboard grids, white callout bars or numbered captions.

## 4. Nine Shots (15s, escalating energy, hard cuts)

1. **0–2s** A cyan shockwave bursts from screen center through particles and light moths; the h3skills.com wordmark slams into place; "One Prompt. Endless Shots." sweeps in below as a bright stroke. Hard cut.
2. **2–3.6s** Glass panels fly in from depth and lock into place, each landing with a soft refractive flash; content is live imagery; full title locks. Hard cut.
3. **3.6–4.8s** A rounded combination mark ignites, glowing outline drawn in one continuous stroke; light moths drift past behind a deep-blue nebula. Hard cut.
4. **4.8–6.4s** A floating edit interface assembles in depth: tool rail slides in from the left, timeline extends right, clip thumbnails fill in, a highlight box snaps to a clip; the lens drifts slightly along the glass. Hard cut.
5. **6.4–8.2s** Full speed: a cyan light bar whips past the lens, her hair flies, particles tear the frame; the lens pushes hard and fast; the title locks mid-motion. The film's energy peak. Hard cut.
6. **8.2–9.6s** A white light-burst explodes on the horizon, GOING LIVE floods the frame huge and complete. Hard cut.
7. **9.6–11.2s** Five vertical content cards fly in and lock into a row, each landing with a cyan edge-flash; content is live; the title locks above. Hard cut.
8. **11.2–12.8s** A 2×2 grid snaps into place, each quadrant landing on its own beat, labels fully seated; all four play live content. Hard cut.
9. **12.8–15s** Particles converge to center; h3skills.com and H3SKILLS lock; a LAUNCHING NOW pill button ignites, glowing outline drawn in one stroke and settling into a steady pulse; the last second everything is static and razor-sharp.

## 5. Hard Rules

- Text always razor-sharp, complete, fully opaque, precisely placed. No blur, ghosting, transparency, scaling, fade, displacement or motion blur. No subtitles/watermarks/corner logos. No full-frame lens flares, no RGB split, no film grain, no black bars, no text outside the glass stroke.
- Energetic, expensive, futuristic; never cheap, never messy, never retro.
- Music: original high-energy tech launch score (deep bass, hard synth hits, rising arpeggios, wide detuned brass, granular riser, one massive impact), no narration/voice.

## 6. Generation

- Mode: I2VA with `@图片1` as the style reference only — never used as the first frame unless explicitly requested.
- 15s, 16:9, native H3 audio.
