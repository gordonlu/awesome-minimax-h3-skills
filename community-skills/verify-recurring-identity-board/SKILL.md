# Blonde Pilot — Coast Highway Vintage Car Fashion Film

Use this Skill when the user wants a **15-second 16:9 cinematic anime fashion short** that proves one character stays identical from start to finish: a blonde female pilot (leather jacket, aviator sunglasses, emerald scarf) beside a parked emerald vintage sports car on a California coast highway at sunset — she leans on the car, adjusts her scarf, walks a few steps, adjusts her sunglasses, and freezes on a hero-frame portrait.

Core principle: **lock the character to the reference and never break identity** — same face, body proportions, hairstyle, outfit and colors in every beat; the car is a static backdrop that never moves; camera is smooth and purposeful.

The prompt follows the three-part H3 structure (core concept → timecoded beats → hard negative rules). I2VA: one character reference image, used only as reference (never as the first frame).

## When to use
- A character showcase / fashion film that must keep one identity consistent
- Anime PV, retro travel-fashion, or road-movie styling
- Any brief where "same person in every shot" is the whole point

## Hard rules
- Reference image locks the character (face, body, hair, outfit, colors, silhouette); do not redesign.
- No costume change, no face change, no body-proportion change, no second person.
- The car stays parked and static; no driving, no reverse, no driverless motion.
- Smooth camera only — no violent shake; shallow DOF, golden sunset backlight.
- No subtitles, no watermark, no extra accessories, no hand distortion.
