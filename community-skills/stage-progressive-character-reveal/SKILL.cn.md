# 角色登场｜细节到全身揭晓 — 电影感角色登场

当用户想要一段**15 秒电影感角色登场短片**、以「局部细节 → 部分身体 → 面部特写 → 全身英雄帧」四段渐进揭示构建时使用，由单张角色参考图生成。

核心原则：**像电影开场一样"排演"角色的登场——从细节揭示到整体，让存在感、剪影、气质与克制的动作承载镜头，并把角色身份锁死参考图，任何界定性特征都不改变。**

提示词遵循 H3 四段式结构（参考锁定 → 核心创意 → 四段渐进揭示 → 严格反向约束）。I2VA：@图片1 仅作人物参考，不作为首帧。

---

## 1. 触发场景

- 游戏 / 动漫 / 电影片头的"渐进式揭示 / 缓慢亮相"角色登场
- 突出角色存在感的电影感镜头：存在感、剪影、气质优先于动作
- "细节先行、英雄帧收尾"、在全片时长内逐级构建揭示的开场

**不要用**这个 Skill 的场景：

- 想要快速动作段落、打斗或机位混乱的镜头
- 想要多角色场面（本技能是单人角色揭示）
- 没有角色参考图

## 2. 输入

- 一张角色参考图（`@图片1`）——锁定角色的脸、身材比例、发型、服装、配色、材质与整体剪影。不重新设计、不简化、不替换任何界定性视觉特征。图中的环境、光影、色调与风格同样作为整体参考。
- 环境以文字描述，契合角色身份与情绪（例如雾港的掌灯人缓步登阶）。
- 时长 15s、画幅 16:9、电影感、高端动漫 / 游戏 / 电影角色开场质感、渲染风格与 `@图片1` 保持一致。

## 3. 四段渐进揭示（带时间码，16:9）

- **0～4 秒（界定性细节）**：从界定性局部开始——靴子、鞋、脚、手、衣摆或重要配件（如提灯）的近景；角色进入画面或站定，镜头缓慢上摇，头发、衣物与次要元素随环境自然飘动。不要杂乱运动、不要过早露出整张脸。
- **4～8 秒（部分身体）**：中景或中全景，从背面 / 侧面 / 四分之三角展示更多身体；角色在环境中平静站定，镜头平滑环绕（truck + pan）或弧形 / 横向移动，逐渐露出角色的脸与剪影。不要机位混乱、不要动作夸张。
- **8～12 秒（面部特写）**：收紧到电影感特写或半身；角色做一个符合性格的标志性小动作（抬下巴、转头、整理衣物、拨开头发、张开手掌、看向镜头或调整站姿）——动作极小而有意图，表情与角色气质一致。不要动作幅度过大、不要表情漂移。
- **12～15 秒（全身英雄帧）**：收尾强全身英雄帧——完整呈现全部设计与剪影，低角度 / 平视 / 略带戏剧性的机位，角色落定一个自然最终姿势并自信保持，干净收尾。不要裁掉脚部或身体、不要换装变脸。

## 4. 硬性规则

- 角色身份锁死 `@图片1`——不换装、不变脸、不复制；角色是全片唯一角色。
- 环境契合角色身份与情绪，不喧宾夺主。
- 镜头平滑、克制、有目的——不做杂乱运动。
- 渲染风格、配色与材质跟随 `@图片1`。
- 无字幕、无水印、无文字。

## 5. 生成

- 模式：I2VA（图生视频），`@图片1` 仅作人物参考——除非明确要求，不作为首帧。
- 15s、16:9、电影感、H3 原生音频。
