GUIDE 02 · 模式选择

T2VA、I2VA、FL2VA、L2VA、Ref2VA 怎么选？

模式不是越高级越好，而是由你手里的素材决定。先看有没有参考图、参考视频，再决定用哪一个。

先看手里有什么：只有文字 → T2VA；一张首帧图 → I2VA；首帧 + 尾帧两张图 → FL2VA；只有尾帧、要倒推开场 → L2VA；有角色图、参考视频或多段音频 → Ref2VA。本站统一使用这五个 *VA 名称，旧资料里的 L2V、S2V 不再作为本站模式名。

五种模式对照表

模式你提供什么控制重点典型用途
T2VA纯文字描述镜头、动作、声音全部由提示词决定概念片、氛围片、纯文字预告
I2VA一张首帧图 + 文字锁定主体外观，动作从首帧往后发展角色出场、产品图动起来、海报活化
FL2VA首帧图 + 尾帧图 + 文字锁定开头和结尾，中间路径可控变身、转场、限定落点的广告镜头
L2VA一张尾帧图 + 文字从给定结尾倒推合理开场先定最终画面，再补过程
Ref2VA角色/主体图 + 参考视频 / 音频锁定身份、动作、节奏与声音舞步复刻、角色一致性、MV、跨界互动

共同点：五种模式都生成视频与音频，都是 24fps；区别在于「哪些信息由你锁定，哪些交给模型补」。锁定越多，结果越可控，但准备成本也越高。

三条决策路径

路径 A：只有文字

用 T2VA。适合还没有拍摄素材、只想快速验证创意的场景。先写一句风格句，再按时间码写动作和镜头，最后写环境声与配乐。参考 H3 提示词怎么写 和 文生宣传片。

路径 B：有参考图

  • 只有一张首帧：I2VA，例如 极简产品广告、第一人称 UGC 测评。
  • 有首帧和尾帧：FL2VA，用于「必须落在这个画面」的转场或变身。
  • 只有尾帧：L2VA，先定最终构图，再让模型补开场。

路径 C：有参考视频、角色图或音频

用 Ref2VA。这是控制力最强的一档：角色图锁身份，参考视频锁动作与节奏，音频锁声音。典型是 动作参考迁移：让角色复刻参考视频里的舞步，并做节拍级对齐。

L2V / S2V 和现在的名字怎么对齐

早期资料里常见的 L2V 和 S2V 容易和现在的五模式混淆。本站统一如下：

旧写法本站现用名说明
L2V（last frame to video）L2VA给定尾帧，倒推开场；同时生成音频
S2V（subject/reference to video）Ref2VA角色、图片、视频、音频多模态参考生成

写提示词或做选型时，以 T2VA / I2VA / FL2VA / L2VA / Ref2VA 为准，避免和站内 Skill、FAQ 的字段名对不上。

按模式找 Skill

  • 不确定提示词结构：H3 提示词写作，覆盖全部五种模式。
  • 要复刻动作：动作参考迁移（Ref2VA / I2VA / FL2VA / L2VA）。
  • 图片做关键帧：图生关键帧短片（I2VA / FL2VA / L2VA）。
  • 纯文字宣传片：文生宣传片（T2VA）。

常见问题

H3 有哪几种生成模式？

T2VA、I2VA、FL2VA、L2VA、Ref2VA 五种。T2VA 纯文字；I2VA 首帧图；FL2VA 首尾帧；L2VA 尾帧倒推；Ref2VA 多模态参考。

只有一张参考图算 I2VA 还是 Ref2VA？

如果只是把这张图当首帧，用 I2VA；如果它要作为贯穿全片的角色/主体身份参考，并且还有动作或声音参考，用 Ref2VA。

旧资料里的 S2V 是什么？

本站现在对应 Ref2VA：角色、图片、视频、音频多模态参考生成。
