GUIDE 03 · 动作迁移

怎么让角色复刻参考视频里的舞步？

角色图锁形象，参考视频锁动作，节拍表锁节奏。这个任务不是一句「让角色跳舞」，而是一次 Ref2VA 结构化迁移。

用 动作参考迁移 Skill。准备三样东西：角色参考图、动作参考视频、迁移等级（逐帧复刻 / 保形换动作 / 局部迁移 / 只借节拍）。再给目标时长、画幅和场景偏好，Skill 会输出可运行的 Ref2VA 六段式提示词。

要准备什么

素材要求作用
角色参考图主体清晰、正面或 3/4 侧面、光线干净锁身份、服装、材质，避免每个镜头换脸
动作参考视频全身入镜、动作完整、节奏可辨锁舞步、肢体轨迹、节拍点
迁移等级四选一，见下一节决定保留多少原动作、允许改多少
目标参数时长、画幅、场景、相机偏好把动作放进你要的广告/短片语境

参考视频不需要和最终画风一致。它只负责动作与节奏；最终风格由角色图、场景描述和提示词决定。

四级迁移怎么选

等级保留什么适合代价
逐帧复刻完整动作顺序、节拍、肢体细节舞蹈挑战、动作教学、MV 对齐对参考视频质量最敏感，机位变化容易穿帮
保形换动作角色身份与体型，动作按新编舞重排同一角色拍多支舞、系列广告需要更明确的节拍表与动作描述
局部迁移只取一个动作母题（抬手、转身、手势）把动作嵌进新场景、新剧情原视频的完整节奏不会被保留
只借节拍重构只保留 BPM 与情绪曲线想要同款节奏但完全新动作动作相似度最低，更像重新编舞

建议先从「保形换动作」试：它既保留角色一致性，又不会因为原视频机位不同而崩。要一比一挑战再升级到「逐帧复刻」。

执行步骤

  1. 先装 Skill：npx skills add https://github.com/gordonlu/awesome-minimax-h3-skills --skill reference-motion-transfer。
  2. 上传角色图与参考视频，告诉 Agent 你要的迁移等级、时长、画幅和场景。
  3. 让 Skill 先出节拍表：标出参考视频的 BPM、关键动作时间点、镜头切换点，再写 Ref2VA 六段式提示词。
  4. 生成后逐项验收：身份是否一致、动作是否漏步、节拍是否对齐、手部是否穿模。先修提示词里的 retention_analysis，再重生成。

不适合哪些情况

  • 没有任何参考视频或参考图，只想用文字描述一段舞：改用 文生宣传片 或 T2VA 工作流。
  • 要求场景和机位与原视频完全不同，却又要逐帧复刻动作：这两件事会互相拉扯，先选一个优先级。
  • 只想做歌词字幕或卡拉 OK：改用 音乐 MV 动态字幕。

常见问题

怎么让角色复刻参考视频的舞蹈动作？

用动作参考迁移 Skill：角色图锁身份，参考视频锁动作，先提取节拍表，再按 Ref2VA 六段式提示词生成。

参考视频和角色图风格不一致可以吗？

可以。参考视频只提供动作与节奏，最终画风由角色图和场景提示词决定。

为什么生成的舞步总是漏动作？

常见原因是迁移等级选得过高、参考视频机位变化太大，或 retention_analysis 没写清必须保留的动作节点。先用「保形换动作」并补齐节拍表。
