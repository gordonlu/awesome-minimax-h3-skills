MiniMax H3 和 H3 Skills 是什么？

一个讲模型，一个讲怎么把模型用对。分清这两层，后面的安装、选模式和写提示词才不会乱。

MiniMax H3 是视频生成模型，负责把文字、图片、参考视频和音频变成带声音的视频。H3 Skills 是给 AI Agent 读取的结构化工作流，负责告诉 Agent：这个任务要什么输入、按什么步骤、输出什么。本站收录 44 个 Skill（10 个官方 + 34 个社区），每个都附真实成片、输入要求、工作流和 npx skills add 安装命令。

MiniMax H3 是什么

MiniMax H3 是 MiniMax 推出的视频生成模型。它支持五种生成模式：T2VA、I2VA、FL2VA、L2VA、Ref2VA；常用时长 5/10/15 秒，续写最长约 21 秒；分辨率覆盖 360p 到 1080p，24fps；画幅包含 1:1、4:3、16:9、9:16、21:9 等。

它的差异点主要在：原生中文渲染、镜头运动控制、物理世界模拟，以及参考视频/音频的多模态对齐。模型本身不等于成片，提示词和工作流决定最终质量。

H3 Skills 是什么

Skill 是一个包含 SKILL.md 的目录。它不是模型，也不是插件，而是一份可被 Agent 读取的工作流说明：输入是什么、先做什么、怎么验收、输出什么格式。

层负责什么例子
MiniMax H3 模型真正生成视频与音频T2VA、I2VA、Ref2VA 推理
H3 Skill把任务拆成可执行步骤与提示词结构动作参考迁移、片头字效、极简产品广告
Agent读取 SKILL.md，按步骤调用模型Cursor、Claude Code、Codex

所以「装 Skill」不是装模型，而是让 Agent 学会一套已经验证过的工作流。安装方法见 H3 Skill 怎么装到 Cursor / Claude Code。

本站能提供什么

  • 44 个 Skill：10 个官方 + 34 个社区原创，按动画、商业广告、创意实验、教育、音乐、游戏、电商分类。
  • 真实成片：每个 Skill 都有由 MiniMax H3 生成的预览视频，标注模式、时长、分辨率与帧率。
  • 可执行信息：输入要求、工作流步骤、适合/不适合场景、安装命令。
  • 官方提示词：49 条官方提示词合辑，按场景分类，一键复制。
  • 选型指南：安装、模式、动作迁移、提示词、中文屏幕字、产品广告、时长分辨率，共 8 篇。

从哪里开始

  1. 先看效果：在 Skill 索引里找与你任务最接近的成片。
  2. 再选模式：看 五种生成模式怎么选，确认你手里素材够不够。
  3. 装进 Agent：按 安装指南 运行 npx skills add。
  4. 写对提示词：按 H3 提示词结构 填字段，再开始生成。

常见问题

MiniMax H3 和 H3 Skills 有什么区别？

MiniMax H3 是生成视频与音频的模型；H3 Skills 是给 Agent 读取的结构化工作流，负责任务拆解、输入要求和提示词结构。

本站有多少个 H3 Skill？

44 个：10 个来自 MiniMax 官方仓库，34 个社区原创。每个都有真实成片、输入要求、工作流和安装命令。

H3 Skills 只能在 Cursor 用吗？

不是。任何能读取 SKILL.md 的 Agent 都可以，包括 Cursor、Claude Code 和 Codex。
