GUIDE 01 · 安装

H3 Skill 怎么装到 Cursor / Claude Code？

H3 Skill 不是插件，而是一份能被 Agent 读取的 SKILL.md。装对位置，Cursor、Claude Code 和 Codex 都能用。

用一条命令装到能读 SKILL.md 的 Agent：npx skills add <repo> --skill <slug>。默认装到当前项目，写入 .cursor/skills、.claude/skills 或 .codex/skills；加 -g 装到用户级目录。装完重启 Agent，再用自然语言点名 Skill。

先分清：Skill 不是插件

Skill 是一个目录，核心是 SKILL.md：里面写清这个工作流解决什么问题、需要哪些输入、按什么步骤执行、输出什么。Agent 读取这份文件后，才会在相关任务里调用它。

所以安装 H3 Skill 不需要给浏览器装扩展，也不需要配置 API Key。你只需要把目录放到 Agent 会扫描的位置。本站每个 Skill 详情页都给出了对应的 npx skills add 命令。

判断标准：如果 Agent 能读取项目文件、能看到 SKILL.md，它就能用这个 Skill。不能读文件的纯聊天窗口，装了也不会自动调用。

Cursor / Claude Code / Codex 对照

三个 Agent 的目录名不同，但读取逻辑一致。下面是项目级与用户级路径：

Agent项目级目录全局目录生效方式
Cursor.cursor/skills/<skill>/SKILL.md~/.cursor/skills/重启 Cursor，在 Agent 对话里直接点名 Skill
Claude Code.claude/skills/<skill>/SKILL.md~/.claude/skills/新开会话，或运行 /skills 查看
Codex.codex/skills/<skill>/SKILL.md~/.codex/skills/新开会话读取；也可在 AGENTS.md 里点名

如果团队要共享，选项目级并把技能目录提交进仓库；如果只是自己常用，选全局，避免每个项目重复安装。

四步安装

  1. 准备 Node.js 与 npx。 在终端运行 node -v 和 npx -v，能输出版本号即可。
  2. 进入项目根目录。 项目级安装必须在你要使用 Skill 的仓库里执行，否则会装到别处。
  3. 运行安装命令。 例如 npx skills add https://github.com/MiniMax-AI/MiniMax-H3 --skill h3-prompt-writing。CLI 会询问安装范围与目标 Agent。
  4. 重启 Agent 并点名。 新开会话后直接说「用 H3 提示词写作 Skill，帮我写一个 15 秒产品广告提示词」。

需要一次装给多个 Agent 时，可以显式指定：npx skills add <repo> --skill <slug> -a "*"，或加 --all 安装仓库里的全部 Skill。

常用安装命令

基础 Skill 来自 MiniMax 官方仓库；社区 Skill 来自本站仓库。两条命令的用法完全一样，只是仓库地址和 slug 不同。

# 基础：H3 提示词写作（官方）
npx skills add https://github.com/MiniMax-AI/MiniMax-H3 --skill h3-prompt-writing

# 动作参考迁移（社区）
npx skills add https://github.com/gordonlu/awesome-minimax-h3-skills --skill reference-motion-transfer

# 片头字效（社区）
npx skills add https://github.com/gordonlu/awesome-minimax-h3-skills --skill kinetic-title-card-generator

# 装到全局目录
npx skills add https://github.com/gordonlu/awesome-minimax-h3-skills --skill reference-motion-transfer -g

# 查看已安装
npx skills list

更多 Skill 的准确 slug 以详情页「安装」区块为准，例如 片头字效、UGC 食品测评、极简产品广告。

怎么确认装好了

  • 目录存在：项目根目录下能看到 .cursor/skills/、.claude/skills/ 或 .codex/skills/。
  • 文件存在：对应 Skill 目录里有 SKILL.md，不是只有一个空文件夹。
  • Agent 能复述：问它「你现在有哪些 Skill？H3 提示词写作的输入是什么？」能答出 integrated_multimodal_description 等字段，说明已经读到。

如果 Agent 说找不到，先确认它打开的是同一个项目目录，再重启会话。大多数「装了没生效」都是装在别的路径，或旧会话没有重新扫描。

常见问题

H3 Skill 需要 API Key 吗？

不需要。Skill 本身是 SKILL.md 工作流说明；真正生成视频仍在 MiniMax H3 的生成界面或 API 中完成。

装到全局还是项目级？

自己常用选全局（-g）；团队共享、要跟着仓库版本走选项目级。

Cursor 里怎么触发 Skill？

重启后在 Agent 对话里直接点名，例如「用动作参考迁移 Skill，让这个角色复刻参考视频的舞步」。
